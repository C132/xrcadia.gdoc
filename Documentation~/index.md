# Google Doc Markdown

Use this package to pull Markdown from a public Google Doc into your Unity project.

- Open the settings window via `xrcadia/Google Doc Markdown/Settings`.
- Add a source entry with a Google Doc URL or ID and an output path (relative to project root).
- Click `Pull Now` on a single source, or use `xrcadia/Google Doc Markdown/Pull All Sources` to pull everything at once.
