# xrcadia.gdoc

An editor-only Unity package that automatically syncs public Google Docs into your project as clean Markdown files.

**Product Page:** [https://c132.github.io/xrcadia.gdoc/](https://c132.github.io/xrcadia.gdoc/)

## Quick Reference

### Setup

1. **xrcadia &rarr; Google Doc Markdown &rarr; Settings** to open the settings window.
2. **+ Add New Source** to add a Google Doc.
3. Enter the document URL or ID and set the output directory.
4. **Pull** to download, or enable **Auto Pull On Editor Startup** to keep docs current.

### Viewing Markdown

- Select any `.md` file in the Project window &rarr; click **View as Markdown** in the Inspector.
- Use the sidebar's file browser to navigate all Markdown files in the project.
- Switch between 11 built-in themes from the viewer toolbar.

### Requirements

- Google Docs must be publicly accessible ("Anyone with the link can view" or published to the web).
- Unity 6000.3 or later.
- Editor-only — zero runtime overhead, zero build impact.
